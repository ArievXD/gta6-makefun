Neon Harbor is an original 2D top-down open-world crime game. You are Rex Marlowe, and you owe the Harbor Syndicate $50,000 — run five story jobs to buy your freedom. Steal cars, outrun the police through the streets of Port Solano, and build your wanted level from 0 to 5 stars, with traffic, pedestrians, combat, and a save in your browser. Plain HTML, CSS, and JavaScript — no build step, no network.

Controls: WASD to move and drive, E to steal a car, mouse to aim, click to shoot, Space to punch or handbrake, Shift for nitro.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
